# 双达标完成规则（2026-10-29）

这是对旧版“学习完成即关闭、完成后仍可打卡”规则的修正，以本页及最新源码为准，历史验收保持原日期与范围。

| 学习完成率 | 打卡率 | 状态与操作 |
| --- | --- | --- |
| 未达100% | 未达100% | 有效周期内进行中，可打卡、填写学习情况 |
| 100% | 未达100% | 继续打卡、填写具体复习情况；分析成功计时，学习进度保持100% |
| 未达100% | 100% | 继续打卡和填写；实际出勤天数可超过目标，打卡率封顶100% |
| 100% | 100% | 自动完成，停止新增打卡和学习记录，保留历史 |

人工结束、取消和超出周期均停止新增。请求携带的状态或页面按钮不能绕过后端判断。两个指标分别展示，首页已完成计划占比按双达标的COMPLETED状态计算。

最后一次有效打卡、步骤完成、成功分析或修改打卡目标后重新计算状态。最后一条使双达标成立的学习记录正常落库并计时，再关闭计划；重发相同requestId复用成功结果。分析失败不计时、不自动打卡。已完成后的新提交拒绝。

V4迁移只纠正旧COMPLETED中未双达标的状态：周期内恢复进行中、未来恢复未开始、过期改为已过期；不删除记录、不修改步骤进度，递增version避免旧页面覆盖。既有V1/V2/V3不修改。

报告可说明：完成率是两个独立度量，状态是二者联合满足后的业务结论；所有写入持有同一父计划行锁，使最后一次打卡与学习提交不会同时越过终态。真实模型负责判断记录相关性，不能决定状态或伪造时长。
