## 录制前准备：这一节不念

1. 启动MySQL、后端、前端和真实AI服务，打开 `http://localhost:5173/#/pages/login/login`。正式录制前预演一次AI生成和学习记录分析。
2. 使用一个没有旧计划的专用本地演示账号；已有旧数据就换一个演示号，不清空日常账号。演示手机号登录不发送真实短信。不要把自己的真实手机号、密码、Token、模型密钥或 `.env` 放进录屏。
3. 把录制当天记作T，提前记好T、T−1、T＋6三个日期。所有“今天”均按上海自然日期。不要在午夜前后录制同一段打卡流程。
4. 打开编辑器，准备以下文件的Markdown预览：根目录 `README.md`、`docs/delivery/开发设计文档.md`、`docs/delivery/AI辅助开发记录.md`、`docs/verification/README.md`。另开终端，工作目录为仓库根目录。若用VS Code，可按Ctrl＋P输入路径，打开后按Ctrl＋Shift＋V预览。
5. 浏览器和终端放在录屏区域；本讲稿放在另一屏或提词器中。操作后停留2～3秒，让老师看清提示和数字。不要把AI失败片段描述成成功。
6. 本稿的A、B、C是三个不同计划，实际标题如下。新建成功后均从“任务”列表点击对应卡片进入详情。
