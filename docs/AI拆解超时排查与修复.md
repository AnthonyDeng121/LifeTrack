# AI服务已启动却显示不可用：2026-10-30排查

本轮需求：用户询问“显示AI服务不可用，怎么回事，你开没开AI”，并要求继续处理。

## 实际原因

AI服务监听127.0.0.1:5001，健康接口status=ok、configured=true，模型glm-4-flash；后端日志也明确请求5001，排除没有启动或连接端口错误。健康只说明进程及密钥配置存在，不证明上游模型可用或输出合格。

现场日志另有上游open.bigmodel.cn连接读取超时。一次拆解首次质量检查未通过，随后第二次生成返回200，但后端在40秒读取窗口已经超时，因此浏览器收到不可用。后端共用40秒预算没有覆盖两次生成，是此次修复的业务原因；不通过放松质量检查来解决。

## 修改前后与方法

- 后端按请求路径区分：普通分析40秒不变，拆解独立90秒。
- 前端拆解预览从75秒、旧直接拆解从50秒统一为100秒；学习提交与补分析仍50秒。
- 上游建连从固定3秒改为可配置默认8秒，读取保持30秒。默认一次上游窗口约38秒，两次约76秒，拆解外层留有余量。网络、DNS和调度仍可能增加等待，不能承诺固定完成时长。
- 增加真实本地HTTP延迟测试：普通分析窗口1秒、拆解5秒，同样延迟1.7秒时拆解成功，分析及报告按短窗口超时。前端实际API封装校验两类预算；其他完整回归和最终真实模型结果见最新证据索引。
