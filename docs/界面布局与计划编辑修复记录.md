# 界面布局与计划编辑修复记录

> 历史阶段记录：结果只对应本文当时的规则与代码，不表示当前版本再次通过。当前统计口径、测试层级、可复现命令及机器证据以[测试与验收可信度整改](测试与验收可信度整改.md)和[最新证据索引](verification/README.md)为准。

日期：2026-10-16。

全选当前列表改为与其他操作一致的玻璃按钮，设置明确内边距和触控尺寸。批量工具栏允许换行，公共按钮移除默认自动外边距。公共页面约束内容宽度，标题区支持换行。

步骤卡片原先仅给操作区保留 118rpx，却同时放置完成、编辑、删除，导致控件压缩和文字截断。现使用明确文字按钮，桌面操作区自适应宽度，手机操作区在正文下方换行。计划卡片和输入框处理窄屏宽度约束。

清理任务、详情、记录、看板、个人页的接口来源、后端调用和数据库写入说明，移除个人页的联调面板，改成学习业务文案。补充前端回归检查，防止这些内部说明重新出现在模板中。

详情页此前缺少编辑弹窗的固定遮罩定位、表单布局和滚动约束。已补齐。第 4 点按“当前无法修正安排，需要修复编辑能力”处理，未禁止编辑，也没有改变课程要求的计划编辑能力。单步骤 100% 权重原本被前端 1–99 的校验拦截，现在与后端 1–100 范围一致。步骤修改和完成后重新读取计划详情，避免显示旧总进度。

验证：

- 使用 Playwright 与本机 Edge 实际打开页面，检查 390px、1280px 两种宽度；任务页 scrollWidth 与视口一致，无横向溢出。
- 手机编辑弹窗宽 358px，桌面宽 560px，均位于视口内；检查任务页、详情页及编辑弹窗截图。
- 创建临时单步骤计划，从页面修改计划名称，打开步骤编辑并保存新的步骤内容，保留 100% 权重。刷新页面后文案仍保留，再通过接口核对持久化结果，最后删除临时计划。
- 前端 API 契约、核心流程检查和 H5 构建通过。本次仅修改前端，未更改后端业务规则。
